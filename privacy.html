Prepared 11 October 2026 for owner review. This describes the current owner-only desktop uploader.

Jaco Taute operates VarysDrogo Owner Uploader to verify his own YouTube channel and upload explicitly approved videos. Contact jacotaute321@gmail.com for privacy questions or deletion requests. Do not email passwords, tokens or private keys.

Sharing and limitations

The uploader does not sell Google user data, use it for advertising, or use it to train AI models. Credentials are not intentionally shared with assistants, campaign providers, Oracle or this website. Google and YouTube receive the requests needed to authorize, upload and verify videos. Public videos, if separately approved, are visible to the public; private videos use YouTube's private visibility controls.

VarysDrogo Owner Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. The application uses YouTube API Services. See Google's Privacy Policy.

Control and deletion

The owner can revoke access through Google Account connections, remove the dedicated Windows credential, remove downloaded OAuth configuration and local records, and separately remove videos in YouTube Studio. Revocation stops future authorized access but does not remove existing copies or videos. This information site has no account database or deletion form.

Website hosting

If published on GitHub Pages, GitHub processes hosting traffic including visitor IP addresses for service/security purposes under its privacy statement. These pages contain no added analytics, advertising, tracking scripts, cookies or embedded videos. External links follow the destination's policies.
